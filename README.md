# Mini Vid

Расширение Google Chrome для просмотра видео в мини-плеере с увеличением под курсором и переходом в отдельное полноэкранное окно.

## Установка

1. Скачайте репозиторий и распакуйте архив.
2. Откройте `chrome://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку проекта.
4. Перезагрузите вкладки с видео.

## Управление

- Кнопка на видео, иконка расширения или `Alt+Shift+P` открывает мини-плеер.
- `F` и кнопка «На весь экран» открывают отдельное окно.
- Нампад `+` / `−` увеличивает область под курсором; двойной щелчок сбрасывает масштаб.
- Кнопка стандартного PiP на сайте перехватывается, когда сайт использует соответствующий браузерный API.

Исходная вкладка должна оставаться открытой. Для защищённых или недоступных потоков используется обычный PiP Chrome. Собственные плавающие блоки сайтов могут требовать отдельной поддержки. Полноэкранное окно не закрепляется поверх других приложений.

## Проверка

Требуется Node.js с поддержкой встроенного тестового раннера:

```sh
node --test tests/player.test.cjs
```

Автоматические тесты используют имитацию браузера; совместимость с конкретными сайтами проверяется отдельно в Chrome.
